# Linting & Formatting (Biome)

Biome is the preferred tool for both linting and formatting in this repository.

## Policy

- Use Biome for lint and format instead of ESLint/Prettier.
- Prefer repository-enforced checks (CI) over editor-only behavior.
- Keep local commands cheap and repeatable.

## Commands

Use the Bun scripts documented in [references/biome.md](../references/biome.md).
